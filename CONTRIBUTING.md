# Contributing to Open Notebook Lab

Thank you for contributing.

## Collaboration model

- Both contributors may improve any course.
- Organize content by **course/subject name only**.
- Do not create contributor-specific, student-specific, university-specific, or degree-specific directories.

## Content status

Use one of these statuses in YAML front matter:

- `draft`
- `in-progress`
- `review-needed`
- `reviewed`

Content marked `reviewed` is treated as the reliable version.

## Required pull request scope

Submit conceptual changes, formula changes, new topics, and cheat-sheet changes through pull requests.

The pull request author must explain:

- What was added or corrected
- Why the change is needed
- Which references were used (if applicable)

## Content organization principle

**Detailed notes explain. Review pages summarize. Cheat sheets compress.**

## Quality expectations

- Keep topic pages structured and educational.
- Keep review pages concise.
- Keep cheat sheets dense and print-friendly.
- Avoid duplicate pages for the same concept.
- Link related topics when relevant.

## Integrity and copyright

- Do not include real university assignments, exams, or official solutions.
- Do not upload copyrighted course materials unless you have clear permission.
- Prefer public references (official docs, open textbooks, papers, public lectures).
